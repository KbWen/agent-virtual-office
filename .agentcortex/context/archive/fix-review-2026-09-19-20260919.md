## Decisions

### D-1: REV-04 (label/bubble layering) is not built → local

- **Decision**: reject the three-layer render split.
- **Reason**: geometry shows an above-head bubble can never be covered by a later-painted (lower) agent — that needs `B.y < A.y − 23`, contradicting the y-sort. Remaining cases are a name tag under a body when two agents are within ~6px of y (the near-stack AVO-156/187 suppress) or transient mid-walk ordering. The fix moves bubbles/labels out of `AgentCharacter`, whose per-frame `renderPos` state is a Protected Surface, for a low-frequency cosmetic case.
- **Alternatives**: React portal into a top-level `<g>` (cheap in code, still re-parents the bubble under a new coordinate root); measure first with the overlap recorder.
- **Re-open condition**: a measured occlusion rate from the overlap recorder or an owner-reported screenshot.

### D-2: REV-06 (monolith extraction) is not built → local

- **Decision**: reject.
- **Reason**: `docs/architecture/monolith-extraction-map.md` says it "is a refactor guard, not a refactor request … extract only when adjacent product work already needs the seam" and "Do not split movement or per-frame render loops just to reduce line count". Its first safe AgentCharacter seam is the watchdog helpers, not `CharacterPixelSprite`.

### D-3: REV-03 deletes the title channel instead of flag-gating it → consolidated: L2 ui-rendering

- **Decision**: delete `listenTitleChanges`, `classifyTitle`, `TITLE_PATTERNS` and their test.
- **Reason**: the handoff's premise ("when the user is looking at other pages") is impossible — a document can only observe its own `<title>`. `index.html` sets a static title and no code writes `document.title`, so the channel has never fired in normal use. The handoff's `OFFICE_ENABLE_TITLE_INFER=1` env flag does not exist in a browser bundle. A flag would keep dead code alive; deletion is the REDUCE move and removes the latent self-feedback path (any future "status in the tab title" feature would otherwise feed back into fabricated `working`).
- **Alternatives**: keep as-is (dead but harmless today); gate behind a `VITE_` flag.
- **ADR-003 check**: line 68 permits ("may remain") passive title heuristics; it does not require them. No ADR change needed.
