## Pass 2: Screen-reduction (visual density) — owner-requested direction

Owner intent: reduce on-screen content / make objects less complex (NOT redesign). Grounded in a
staged busy-moment screenshot (`.pet-shots/clutter-audit.png`, 6 agents, 3 bubbles, blocked badge,
pair-link, weather+pet on).

**Scene inventory (what's drawn):** 12 Plants, 12 WallWindows, 5 CoffeeCups, 4 Bookshelves, 2 Rugs,
2 Clocks + ~25 singleton objects + overlays (FlyingDocuments, EventJuice, PairLink, HelperHuddles,
NightSky, weather, pet, dog, GateWaitingTray). TopDownFurniture = 103 SVG primitives / ~20 components
(~5 each). AgentCharacter = 55 primitives (the focal point — keep detailed).

**Adversarial correction to the framing:** at actual render zoom, individual objects are NOT
over-complex (~5 primitives each, like Plant). The problem is *aggregate count/density*, not
per-object complexity. So "simplify objects" is the wrong lever; "reduce decoration count" is right.

### Reduction candidates (ranked; each gated on: must NOT reduce status visibility = core value)

- **VR-1 — Thin the Plants 12 → 6 (DONE, 2026-06-20).** [TopDownFurniture.jsx:130](../../src/components/TopDownFurniture.jsx#L130)
  `Plant({x,y})` takes position only — **pure decoration, zero signal binding**. Thinned to a
  6-plant symmetric perimeter frame (corner + mid-side; dropped 4 redundant stacked pairs + the
  center-lounge crowder). Guarded by `tests/officeDecorationDensity.test.js` (count∈[4,6], no
  desk-zone plant, no <40px cluster). Evidence: guard 3/3 + `npm run smoke` PASS 4 viewports 0
  errors; before/after `.pet-shots/clutter-before.png` vs `clutter-after.png`.

- **VR-2 — Object restyle pass via 5-expert design/game panel (DONE, 2026-06-20).** Owner asked to
  *restyle* objects (recolor/resize), not just remove. Ran a 5-lens panel (cozy-interior, pixel-art
  director, cozy life-sim game designer, color art-director, honesty/signal adversary) →
  synthesizer. **Palette thesis:** the office had a warm-wood cozy core but the lounge couch was the
  single coldest object (`#7B8FA1` grey-blue) sitting in the chill zone. The adversary lens pulled
  the group back from full terracotta (would collapse into wood + drift into agent-clothing hues,
  hurting figure-ground) to a *desaturated* clay. Implemented (all pure fill swaps, silhouettes
  unchanged):
  - Couch → clay ramp: base `#7B8FA1→#B97A4E`, cushions `#8FA3B8→#CC8C5E`, top `#5A6E80→#9A5E38`,
    arms `#6B7F91→#A86B44`. Separates cleanly from the green rug (verified live).
  - CoffeeMachine body `#444→#5A4A3E` (espresso) — green CAFE screen + red blink carved out, pop harder.
  - WaterCooler housing `#ccc→#D8CDBE` (putty) — blue bottle untouched (the one cool accent).
  - **RoundTable opacity nudge: SKIPPED** — panel gated it on "table looks flat live"; it doesn't.
  - **Skipped by panel:** full-brown couch (figure-ground), seat-highlight add-shape, plant pot/leaf
    recolors (churn, protect the only greens), printer/server warm (keep machines as cool ballast),
    and ALL signal-bearing looks (windows/monitors/gate/kanban/rug hues/clocks).
  - Evidence: render-smoke PASS 4 viewports 0 errors; `.pet-shots/recolor-before.png` vs
    `recolor-after.png` + `lounge-zoom.png`. Honesty preserved: no signal-bearing color touched.
- **VR-2 — Empty-room imbalance (NOT a removal target).** Top-right meeting room + bottom-right are
