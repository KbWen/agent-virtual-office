## 2. System Map (application)

- **Stack**: React 19 + Vite 6 + Zustand 5 + Tailwind 4. CommonJS package, Node ≥22, MIT. Version `1.2.1`.
- **Product**: pixel-art virtual office visualizing AI-agent activity in real time, source-agnostic (Claude Code / Gemini / Codex / any POST `/api/status`).
- **Entry points**:
  - `bin/cli.js` — installable CLI launcher (hoist-safe Vite spawn).
  - `server.mjs` — Node SSE + static server (`/api/status`, `/api/event`, session scan/merge).
  - `vite` dev / `src/main.jsx` + `index.html` — frontend.
- **Source layout** (`src/`):
  - `components/` — UI (PixelOffice, AgentCharacter, ControlPanel, AgentInspector, ActivityFeed, NarrowRoster, HelperHuddle, TopDownFurniture, BehaviorBubble, ErrorBoundary).
  - `systems/` — `store.js` (zustand SSoT), `classify.js` (4-tier task/status/mood/role classifier + `decideBehavior` resolver), `movementSystem.js`, `moodEngine.js`, `behaviorEngine.js`, `officeLife.js`, `rosterModel.js`, `constants.js`.
  - `inference/` — `agentRouter.js`, `idleGapInfer.js`, `desktopNotifier.js`, `workflowHandoff.js`, `inferStatus.js`.
  - `server/scanSessions.mjs`, `utils/`, `config/`, `locales/` (en + zh-TW), `i18n.js`.
- **Data flow**: hook (`public/hooks/office-status-hook.js`) → status file / `POST /api/status` → server scan+merge → SSE → `store.applyExternalStatus` → `decideBehavior` → render. Behavioral correctness is **test-authoritative** (vitest = real modules); pixel/visual correctness is **owner-confirm only** (`preview_screenshot` hangs in this env — see SSoT Protected Surfaces).
